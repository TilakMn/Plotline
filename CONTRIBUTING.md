# Contributing to Plotline

Thanks for helping. Plotline is early, so feedback is as valuable as code.

## Ways to help

- **Report a bug:** open an issue with what you did, what you expected and what happened.
  Include your browser and a screenshot if you can.
- **Suggest a feature:** open an issue describing the problem you want solved, not only the solution.
- **Share how your team works:** which methodology you really use and how you prioritize.
  This shapes the roadmap.
- **Send code:** see below.

## Working on the code

The whole app is `index.html`. Open it in a browser, edit it, and reload.

1. Fork the repository and create a branch: `git checkout -b my-change`.
2. Keep changes focused: one fix or feature per pull request.
3. Test in a desktop browser and at a phone width (about 380 px), in light and dark mode.
4. Open a pull request explaining what changed and why. Screenshots help.

## Guidelines

- Plain JavaScript and CSS, no build step.
- Write interface text in plain, friendly language. Explain techniques for people who are new to them.
- Keep the app usable on phones and with a keyboard.
